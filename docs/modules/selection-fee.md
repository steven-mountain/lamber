# 采购甄选费测算模块设计

本模块位于 ICT 生命周期测算的投入侧，用于按供应商报价、代理服务费上浮和甄选最高限价辅助填写用户指定的投入科目与甄选费用。

## 核心规则

1. 供应商报价与甄选最高限价存在互斥固定锚点，状态为 `selectionFeeAnchor: "quote" | "limit"`。
2. 默认固定供应商报价，保持旧行为：供应商报价或上浮价格变化时，调用 `calculate_selection_fee` 正向计算甄选费、实际测算成本和最高限价。
3. 固定甄选最高限价后，上浮价格变化时，调用 `reverse_calculate_selection_fee` 反向计算供应商报价、甄选费和实际测算成本，最高限价本身保持不变。
4. 直接编辑供应商报价时，供应商报价自动成为固定锚点；直接编辑最高限价时，最高限价自动成为固定锚点。
5. 连续输入会使用请求序号丢弃过期异步结果，避免较慢的旧计算覆盖用户最新输入。
6. 甄选服务费由供应商承担并已包含在最高限价中。写入时目标投入科目金额为 `最高限价 - 甄选服务费`（等价于 `供应商报价 + 上浮`），`中标服务费`科目写入甄选服务费，两者合计等于最高限价。

## UI 规则

供应商报价和甄选最高限价标题旁各显示一个圆点按钮。圆点按钮使用 `aria-pressed` 表示当前固定状态，点击其中一个会取消另一个固定状态。输入框保留原数值输入方式。

“写入投入科目”选择器从统一 `ICT_SUBJECT_DEFINITIONS` 目录读取全部投入科目，并按 IT/移动云、CT、非IT/CT与综合类分组展示。`中标服务费`是系统自动写入科目，不可同时作为目标科目。旧方案或无效科目代码默认回退到 `cost_it_integration`，按钮文案随目标科目动态变化。

## 集成边界

甄选费用公式仍由 Rust 后端 `calculate_selection_fee` 与 `reverse_calculate_selection_fee` 负责；前端只选择调用方向并展示结果。点击写入后通过统一批量科目更新入口同时更新目标投入科目和 `costIt.bidding`，统一同步科目资金计划，并继续执行既有含税归一与 0 容差财务校验规则。智能反算仅在反算当前甄选目标科目时，按“目标科目 = 报价 + 上浮”回推报价并刷新甄选面板。

甄选测算面板的供应商报价、上浮、实际测算成本、甄选费、最高限价、固定锚点和目标科目代码作为 `IctInput` 可选元数据保存。目标科目按方案随 lifecycle 工作副本和效益快照恢复；历史数据缺少字段时默认集成服务。除用户点击写入后形成的正式科目金额外，面板元数据本身不参与效益测算公式。生成《效益分析表》时，只有面板已有报价、限价或测算结果，才将供应商报价写入 `3-直接经济效益评估表!T26`，将甄选上浮写入 `3-直接经济效益评估表!T29`；导入同类 Excel 无目标科目信息，默认恢复为集成服务。
