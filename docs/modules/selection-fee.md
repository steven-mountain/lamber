# 采购甄选费测算模块设计

本模块位于 ICT 生命周期测算的投入侧，用于按供应商报价、代理服务费上浮和甄选最高限价辅助填写 IT 集成服务投入与甄选费用。

## 核心规则

1. 供应商报价与甄选最高限价存在互斥固定锚点，状态为 `selectionFeeAnchor: "quote" | "limit"`。
2. 默认固定供应商报价，保持旧行为：供应商报价或上浮价格变化时，调用 `calculate_selection_fee` 正向计算甄选费、实际测算成本和最高限价。
3. 固定甄选最高限价后，上浮价格变化时，调用 `reverse_calculate_selection_fee` 反向计算供应商报价、甄选费和实际测算成本，最高限价本身保持不变。
4. 直接编辑供应商报价时，供应商报价自动成为固定锚点；直接编辑最高限价时，最高限价自动成为固定锚点。
5. 连续输入会使用请求序号丢弃过期异步结果，避免较慢的旧计算覆盖用户最新输入。

## UI 规则

供应商报价和甄选最高限价标题旁各显示一个圆点按钮。圆点按钮使用 `aria-pressed` 表示当前固定状态，点击其中一个会取消另一个固定状态。输入框保留原数值输入方式，不额外增加说明文案，维持简单测算面板。

## 集成边界

甄选费用公式仍由 Rust 后端 `calculate_selection_fee` 与 `reverse_calculate_selection_fee` 负责；前端只选择调用方向并展示结果。点击“填入集成服务”仍将最高限价写入 `costIt.integration.incl`，将甄选费写入 `costIt.bidding.incl`，不改变科目资金计划同步和 0 容差财务校验规则。
