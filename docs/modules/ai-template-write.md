## 字段与权限

统一目录 `src-ui/src/lib/templateCompletion/catalog.json` 按模板声明字段。需求表保留8个text；立项支持IT/CT与两条收付款，共4个；甄选作为仅改数据的扩展验证加入8个gen_zx_*及收付款，共10个。只有text可写，derived/check/list/image均在服务端拒绝；三张无人工字段模板显式排除。项目背景来自项目基本信息，是派生只读，不跨存储边界写入。

文本默认位于formData，stateKey可声明原有根状态位置。收付款写入revCollection/expPayment，审批旧值读取和版本复核使用同一目录取值逻辑，前端同步至既有状态拥有者，避免生成读取旧值。详细契约见[目录README](../../src-ui/src/lib/templateCompletion/README.md)。

Rust 拒绝非文本、未知字段、金额、税率、年限、折现率及测算结果；单字段允许 1–20000 字，不能变更审批中的项目、模板或字段集合。插件取可信 ACP 身份，审批前与实际写入前均校验工作区及绑定项目；通用聊天、缺失绑定和其他项目拒绝写入。

## 审批与保存

审批意图由已保存模板读取旧值，并绑定工作区、模板版本及本次字段集合。沿用既有审批等待、超时拒绝和两版审计。业务写入直接在 Rust 消费一次性批准参数；普通 reviewed-arguments 路由仅可用于演练 marker，不能取走业务授权再绕过版本核对。

工具与 UI 共同调用 `save_template_state_locked`：这是原保存命令的事务主体，保留原校验、标准状态与兼容镜像更新，没有新表、迁移或独立写 SQL。工具只合并批准的 formData 文本，保留其他字段、资产、映射和输出设置。

为防审批期间模板被修改，复用已有 template_version 做乐观锁；兼容历史状态时还复核已展示的旧字段值。持有工作区/连接锁直到提交，避免工作区切换。版本冲突、授权缺失或消费后重试均拒绝，必须重新读取及审批。

## 模板页同步

工具提交后发出 `lamber-template-text-changed`，按工作区、项目、模板、版本定位。界面以“上次保存值 / 当前草稿 / 批准值”进行三方合并，保留无关草稿，同字段冲突或版本跳跃则停止旧副本自动保存并展示恢复入口。

模板页载入有身份与序号校验，保存串行化并携带 expectedVersion，生成先完成同一路径保存。这样既防止旧 autosave 覆盖批准文本，也防止生成读取未解决的冲突。不能靠延时重载整页或只修改界面文字实现同步。

桥接契约为 v5，开发插件、staging 资源与 Rust 二进制必须同代构建。财务公式、0 容差门禁和 docfill 引擎未改动。

验证及真人步骤见 [template-write-b.md](../verification/template-write-b.md)。

## 主动读取（2026-09-07 补充）

read_template_fields(templateId) 不收 projectId，沿现有绑定权限取得目标；通用拒绝、无需审批。复用现有模板状态和资产读函数，按目标模板目录投影，不返回路径/输出配置/映射。以valueSource区分已保存、默认与空值。

插件构建直接编译UI的catalog.ts纯函数，需求表兼容入口与立项完成度同用该算法。Rust仅提供按目录投影的完整存在标志、条件开关、安全列表列和资产状态；截断不影响缺项判断。外部derived/check与未保存动态默认值无法判定时evaluated=false，单独计入unknownCount，不进入missingFields，不声称整表通过。

读取别名仅在当前绑定项目有唯一已保存候选时解析；歧义要求完整模板名称。无保存态的精确模板名返回hasSavedState=false及已标识的默认值/动态默认未知状态。目录随构建嵌入，不是运行时热更新；生成数据保持为JSON，扩展连生成TypeScript也无需变化。

本轮泛化证据及真人待办见[字段目录验证](../verification/template-field-catalog.md)。原需求表主动读取证据见[读取验证](../verification/template-read.md)。

“补充二”已将聊天图片卡片改为独立产品读取通道，仅在本轮用户明确要求填写/输入或生成需求导入表时，按绑定项目和共享目录缺项展示，不改页面被动注入。绑定、普通聊天和只读查询不触发；历史请求不永久开启。读工具说明与系统提示遵守同一意图条件，激活后才引导用户使用聊天上传卡片，并明确模型不能直接写图；实际写入继续由用户选图/粘贴触发原资产命令。见[附件设计](./template-state-and-assets.md)与[验证](../verification/demand-upload-decoupling.md)。
