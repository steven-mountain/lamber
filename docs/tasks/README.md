## 写任务书的约定

- **事实要带 `file:line`**，让接手的人不用重新调研，也让过时的结论能被发现。
- **"不要做的事"和"要做的事"同等重要**——它防的是顺手扩大范围。
- **验证要求写清"怎么算通过"**，并且照实区分"已验证"与"未验证 / 已知限制"；
  没跑过的路径不许记成通过。
- 结论被后续实测推翻时，**在原地标注更正**（保留原判断 + 写明错在哪），
  不要静默改掉——否则没人知道旧结论还散落在别处。
