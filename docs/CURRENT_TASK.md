# 智算测算页面信息结构优化

- **Status:** Done
- **Objective:** 将收入/成本项整理为摘要卡与三 Tab 详情编辑结构，固定右侧只读效益结论栏，并保持现有计算、保存、ICT 同步和资金计划数据流不变。

## Progress

1. [x] 收入/成本项默认仅展示启用状态、名称、税率、含税/不含税金额、占比、ICT 状态、资金计划状态和公式摘要。
2. [x] 每个计算项保留向下展开交互，展开后仅显示“项目编辑 / 计算公式 / 资金计划”三个 Tab。
3. [x] ICT 同步科目、参与测算和参与自动同步配置统一归入“项目编辑”，不新增 ICT 独立 Tab。
4. [x] 公式编辑器和资金计划校验继续复用原组件及 store action；资金计划移除第二层独立折叠。
5. [x] 效益结论改为固定只读分组侧栏，集中展示结论、核心金额、收益指标、关键构成和输出操作。
6. [x] 主内容与侧栏采用 `minmax(0, 1fr)` 响应式布局，窄屏改为纵向排列，避免页面级横向溢出。

## Validation

- `npx tsc --noEmit`
- 定向 ESLint
- `npm run test:ai-compute-quote`
- `npm run build`
- 本地浏览器检查收入/成本摘要、三 Tab 展开和右侧结论布局

## Scope Boundary

- 未修改报价公式、金额重算、资金计划生成或 0 差异校验规则。
- 未修改蓝图持久化、自动保存、ICT 同步事务或人工覆盖处理。
- 展开状态和详情 Tab 状态仍为本地 UI 状态，不进入业务序列化数据。
